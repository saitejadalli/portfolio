# Saiteja Dalli: data analytics portfolio

Static site (no build step): `index.html`, `style.css`, `main.js`.

## Publish on GitHub Pages
1. Create a public repository (e.g. `portfolio`, or `<username>.github.io` for a root URL).
2. Upload every file in this folder to the repository root.
3. Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. The site goes live at `https://<username>.github.io/<repo>/` after a minute or two.
